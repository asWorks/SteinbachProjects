✅ OPTION 1: Private DLL-Deployment (BEVORZUGT)
--------------------------------------------------------------------------------
VORTEILE:
- Projekt wird portable und unabhängig von Installationen
- Alle Dependencies im Projektverzeichnis
- Einfaches Deployment auf neue Rechner
- Versionskontrolle über Git möglich

NACHTEILE:

- Möglicherweise rechtliche Grauzone bei DLL-Kopie

VORGEHENSWEISE:

Schritt 1: DLLs vom ALTEN PC sammeln
-------------------------------------
Auf dem ALTEN PC folgendes PowerShell-Skript ausführen:

```powershell
# Datei: Collect-ThirdPartyDlls.ps1
# Auf dem ALTEN PC ausführen

$projectRoot = "C:\Users\Noone\Documents\Visual Studio 2017\Projects\SteinbachSolutions\SteinbachProjects"
$libsFolder = Join-Path $projectRoot "libs"

# Ordnerstruktur erstellen
$c1Folder = Join-Path $libsFolder "ComponentOne"
$arFolder = Join-Path $libsFolder "ActiveReports"
$sfFolder = Join-Path $libsFolder "Syncfusion"

New-Item -ItemType Directory -Force -Path $c1Folder
New-Item -ItemType Directory -Force -Path $arFolder
New-Item -ItemType Directory -Force -Path $sfFolder

# Kopiere aus bin\Debug (bereits kompiliert mit allen Dependencies)
$binDebug = Join-Path $projectRoot "Projekte\bin\Debug"

if (Test-Path $binDebug) {
    Write-Host "Sammle DLLs aus: $binDebug"

    # ComponentOne DLLs
    Copy-Item "$binDebug\C1.*.dll" -Destination $c1Folder -Verbose

    # ActiveReports DLLs
    Copy-Item "$binDebug\GrapeCity.*.dll" -Destination $arFolder -Verbose

    # Syncfusion DLLs
    Copy-Item "$binDebug\Syncfusion.*.dll" -Destination $sfFolder -Verbose

    Write-Host ""
    Write-Host "✅ DLLs erfolgreich gesammelt!" -ForegroundColor Green
    Write-Host "Ordner: $libsFolder" -ForegroundColor Yellow
    Write-Host ""
    Write-Host "NÄCHSTE SCHRITTE:"
    Write-Host "1. Ordner 'libs' zum Git-Repository hinzufügen"
    Write-Host "2. Commit und Push durchführen"
    Write-Host "3. Auf neuem PC: Repository klonen"
    Write-Host "4. Projekt-Referenzen anpassen (siehe CP_Aenderungen.txt)"
} else {
    Write-Host "❌ Fehler: $binDebug nicht gefunden!" -ForegroundColor Red
    Write-Host "Bitte erst das Projekt kompilieren (Debug-Build)!"
}
```
